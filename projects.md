## Data Analytics & Machine Learning

### MLB Player Projection Model

A machine learning project focused on predicting future MLB strikeout rate using previous-season performance, Stuff+, workload, and age.

**Methods:** Python, R, Random Forest, Linear Regression, chronological validation

**Key questions:**
- How persistent is strikeout rate from one season to the next?
- How does pitcher workload affect year-to-year stability?
- Does Stuff+ add predictive value beyond previous-season strikeout rate?
- How much does a model improve when additional information is included?

[View the project on GitHub](https://github.com/eimioda)

### MLB Pitching Performance Analysis Using Statcast Data

An analysis of pitch-level MLB Statcast data examining pitching performance, stability, and predictive value across multiple seasons.

**Methods:** R, baseballr, tidyverse, ggplot2

**Analysis included:**
- Strikeout rate (K%)
- Ground-ball rate
- K-BB%
- BABIP
- HR/FB
- Pitch usage by hitter handedness and pitch count

[View the project on GitHub](https://github.com/eimioda)
